# \# Authentic RAG: การเปรียบเทียบระบบก่อนและหลังการปรับปรุงการค้นคืนข้อมูล

# 

# \## 1. ที่มาและวัตถุประสงค์ของโครงการ

# 

# โครงการนี้มีวัตถุประสงค์เพื่อเปรียบเทียบประสิทธิภาพของการค้นคืนข้อมูลในระบบ Retrieval-Augmented Generation (RAG) ระหว่างระบบก่อนปรับปรุง (Baseline) และระบบหลังปรับปรุง (Improved)

# 

# ระบบ Baseline ใช้การค้นคืนข้อมูลแบบผสมผสาน (Hybrid Retrieval) โดยรวมการค้นหาด้วยคำสำคัญ การค้นหาด้วยความหมาย และการรวมอันดับผลการค้นหา ส่วนระบบ Improved เพิ่มการขยายการค้นคืนด้วยกราฟความรู้ (Graph Expansion) และการจัดอันดับเอกสารใหม่ด้วย Cross-Encoder Reranking

# 

# การทดลองนี้คงโมเดลที่ใช้สร้างคำตอบสุดท้ายไว้เหมือนเดิม เพื่อให้สามารถศึกษาผลของการเปลี่ยนแปลงกระบวนการค้นคืนข้อมูลได้โดยตรง

#

# 

# \## 3. ระบบก่อนปรับปรุง (Baseline)

# 

# ระบบ Baseline ใช้การค้นคืนข้อมูลแบบผสมผสาน ประกอบด้วยขั้นตอนหลักดังนี้

# 

# 1\. \*\*BM25:\*\* ค้นหาเอกสารจากความตรงกันของคำสำคัญในคำถามและเนื้อหาเอกสาร

# 2\. \*\*BGE-M3:\*\* แปลงข้อความเป็นเวกเตอร์ (Embedding) เพื่อค้นหาเอกสารที่มีความหมายใกล้เคียงกับคำถาม

# 3\. \*\*Reciprocal Rank Fusion (RRF):\*\* รวมอันดับจากการค้นหาแบบ BM25 และการค้นหาแบบเวกเตอร์

# 4\. \*\*การเลือกเอกสาร Top-k:\*\* เลือกเอกสารที่มีอันดับสูงเพื่อนำไปใช้เป็นบริบทในการสร้างคำตอบ

# 

# แนวทางนี้ช่วยรวมข้อดีของการค้นหาด้วยคำสำคัญและการค้นหาเชิงความหมาย อย่างไรก็ตาม ระบบยังไม่มีขั้นตอนขยายผลการค้นคืนผ่านความสัมพันธ์ระหว่างเอนทิตีในกราฟความรู้ และไม่มีการจัดอันดับใหม่ด้วย Cross-Encoder

# 

# \## 4. ระบบหลังปรับปรุง (Improved)

# 

# ระบบ Improved พัฒนาต่อยอดจากระบบ Baseline โดยเพิ่มการค้นคืนข้อมูลผ่านกราฟความรู้และการจัดอันดับเอกสารใหม่ มีขั้นตอนดังนี้

# 

# 1\. \*\*Hybrid Retrieval:\*\* ค้นหาเอกสารเบื้องต้นด้วย BM25 และ BGE-M3 จากนั้นรวมอันดับด้วย RRF

# 2\. \*\*การค้นหาเอนทิตีตั้งต้น (Graph Seed Identification):\*\* ระบุเอนทิตีในกราฟที่เกี่ยวข้องกับเอกสารที่ค้นพบ

# 3\. \*\*การขยายกราฟ (Graph Expansion):\*\* สำรวจเอนทิตีที่เชื่อมโยงกันผ่านความสัมพันธ์ในกราฟ เพื่อค้นหาข้อมูลเพิ่มเติมที่อาจเกี่ยวข้องกับคำถาม

# 4\. \*\*การค้นคืนเอกสารจากกราฟ:\*\* ใช้เอนทิตีที่ได้จากการขยายกราฟเพื่อค้นหาเอกสารเพิ่มเติม

# 5\. \*\*การรวมรายการเอกสาร (Candidate Merging):\*\* รวมเอกสารจาก Hybrid Retrieval และการค้นคืนจากกราฟ พร้อมลดรายการที่ซ้ำกัน

# 6\. \*\*การจัดอันดับใหม่ (Cross-Encoder Reranking):\*\* ประเมินความเกี่ยวข้องระหว่างคำถามกับเอกสารแต่ละรายการ แล้วจัดอันดับใหม่

# 7\. \*\*การสร้างบริบท:\*\* เลือกเอกสารอันดับสูงสุดเพื่อส่งให้โมเดลสร้างคำตอบ

# 

# ไฟล์ `build\_graph.py` ใช้สร้างกราฟความรู้จากเอกสารในฐานความรู้ และจัดเก็บผลลัพธ์ไว้ใน `graph.json` ตามตำแหน่งที่กำหนดในโค้ด

# 

# \## 5. ความแตกต่างระหว่างระบบก่อนและหลังปรับปรุง

# 

# | องค์ประกอบ | Baseline | Improved |

# |---|---|---|

# | การค้นหาด้วยคำสำคัญ | BM25 | BM25 |

# | การค้นหาเชิงความหมาย | BGE-M3 | BGE-M3 |

# | การรวมอันดับผลการค้นหา | RRF | RRF |

# | การขยายการค้นคืนด้วยกราฟ | ไม่มี | มี |

# | การค้นคืนเอกสารเพิ่มเติมจากกราฟ | ไม่มี | มี |

# | การจัดอันดับใหม่ด้วย Cross-Encoder | ไม่มี | มี |

# | โมเดลสร้างคำตอบสุดท้าย | Qwen | Qwen รุ่นเดิม |

# 

# \### 5.1 เหตุผลในการปรับปรุง

# 

# \*\*1. Graph Expansion\*\*

# 

# เอกสารที่เกี่ยวข้องกับคำถามอาจไม่ได้ใช้คำสำคัญเดียวกับคำถามโดยตรง แต่มีเอนทิตีหรือแนวคิดที่เชื่อมโยงกับข้อมูลที่ต้องการ การขยายกราฟช่วยค้นหาความสัมพันธ์เหล่านี้และนำข้อมูลที่อาจเกี่ยวข้องกลับมาพิจารณาเพิ่มเติม

# 

# \*\*2. Cross-Encoder Reranking\*\*

# 

# การค้นคืนเบื้องต้นช่วยค้นหารายการเอกสารที่มีแนวโน้มเกี่ยวข้องได้อย่างรวดเร็ว แต่ลำดับเอกสารอาจยังไม่สะท้อนความเกี่ยวข้องกับคำถามอย่างละเอียด Cross-Encoder จึงถูกนำมาใช้ประเมินคู่ข้อความระหว่างคำถามและเอกสาร แล้วจัดอันดับเอกสารใหม่

# 

# \*\*3. การคงโมเดลสร้างคำตอบเดิม\*\*

# 

# ทั้งสองระบบใช้โมเดล Qwen รุ่นเดิมในขั้นตอนสร้างคำตอบสุดท้าย เพื่อให้การเปรียบเทียบมุ่งเน้นไปที่การเปลี่ยนแปลงกระบวนการค้นคืนข้อมูล ไม่ใช่การเปลี่ยนโมเดลสร้างคำตอบ

# 

# \### 5.2 ผลที่คาดหวัง

# 

# การเพิ่ม Graph Expansion อาจช่วยให้ระบบค้นพบเอกสารที่เกี่ยวข้องผ่านความสัมพันธ์ระหว่างเอนทิตี ขณะที่ Cross-Encoder Reranking อาจช่วยให้เอกสารที่เกี่ยวข้องกับคำถามมากกว่าอยู่ในอันดับสูงขึ้น

# 

# อย่างไรก็ตาม ยังไม่สามารถสรุปได้ว่าระบบ Improved มีประสิทธิภาพดีกว่าระบบ Baseline จนกว่าจะมีผลการทดลองและตัวชี้วัดรองรับ
